# Glossary - Apple Hardware

Apple's devices and special instructions. Stela imitates most of these in software.

| Term | Meaning |
|---|---|
| **AMX** | Apple's undocumented matrix coprocessor instructions |
| **WKdm** | Page compression; Apple has private instructions for it |
| **AIC** | Apple Interrupt Controller |
| **PMGR** | Power manager |
| **DART** | Apple's IOMMU |
| **ANS** | Apple's NVMe storage controller |
| **SMC** | System Management Controller |
| **SEP** | Secure Enclave Processor |
| **DCP** | Display Coprocessor |
| **AGX** | Apple's GPU |
| **RTKit / ASC** | The small OS on Apple's helper processors, and how the main CPU messages them |
| **Metal, AIR, MTLB** | Apple's graphics API, its shader IR, and its library container |
| **kext** | Kernel extension |
